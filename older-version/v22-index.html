🏠 What This Screener Does

A single-file, no-login NSE stock screener built for momentum and relative-strength based research.

This tool loads a daily snapshot of NSE-listed stocks (m.json) and gives you fast, flexible ways to filter, rank, and compare them — entirely in your browser, with no server or account needed.

🧭 Core building blocks
  • Filters — narrow thousands of stocks down to a focused list using sector, RS, market cap, fundamentals, and more.
  • RS Rating — a composite Relative Strength score (0–400) ranking each stock's price momentum against the rest of the market.
  • Peer Comparison — click any stock's code to instantly see how it stacks up against others in the same industry/basic industry.
  • Industry Performance — a market-wide heatmap of average returns by sector/industry, drillable down to basic industry.
  • Saved Searches — name and store filter combinations locally, re-run one or combine several at once.
  • TradingView Export — turn any filtered result into a ready-to-import TradingView watchlist.
New here? Start with the Filters tab to learn the basics, then check RS Rating to understand the most important column in the table.

⚙ Filters Panel

Click the ⚙ Filters button in the header to show or hide this panel.
🔎 Text & dropdown filters
  • Search Code/Name — instant text match on stock ticker or company name.
  • Macro Sector / Sector / Industry / Basic Industry — multi-select dropdowns; tick multiple values in one dropdown for an OR match (e.g. Auto + IT), while different dropdowns combine with AND logic.
  • Price Band % — NSE's circuit filter band (0/2/5/10/20%), also multi-select.
📏 Range filters

Most numeric fields (RS Total, RS 1M/2M/4M/6M, Market Cap, PE, Close Price, ROE, Turnover, Promoter Holding, EPS/Sales growth) accept a Min and/or Max — leave either blank for an open-ended range.

✅ Checkbox filters
  • Volume / Turnover / Delivery Above Avg — flags stocks trading with unusually high activity.
  • Is Tradable ⚡ — the most important quick-filter; highlights stocks flagged as currently tradable, with a glowing row highlight in the table.
🧹 Clearing & saving

Use ✕ Clear to reset every filter at once. Use 💾 next to it to save your current combination as a named search for later (see the Saved Searches tab).

🔗 Sector Cascade Logic

The four classification dropdowns are linked — selecting a parent narrows the children automatically.

NSE classifies every stock into a 4-level hierarchy:

Macro Economic Sector → Sector → Industry → Basic Industry

How the cascade behaves
  • Picking one or more Macro Sectors instantly limits the Sector dropdown to only the sectors that exist under those macro sectors — and does the same further down to Industry and Basic Industry.
  • Picking Sectors narrows Industry and Basic Industry the same way, regardless of what Macro Sector is selected.
  • Picking Industries narrows Basic Industry to just that industry's sub-categories.
  • Clearing a parent selection automatically widens its children back out.
Why this matters: you'll never accidentally pick a combination that returns zero stocks — every dropdown only ever shows options that actually exist given what's already selected above it.

📋 Reading the Table

Every column header is clickable to sort — click again to reverse direction.
Price & momentum
  • Close — latest closing price.
  • NR — Narrow Range day count; amber number shown only when ≥1, meaning the stock has been consolidating in a tight range for that many days (often a pre-breakout signal).
  • 1D/1M/2M/4M/6M Chg% — price change over each timeframe, green for gains, red for losses.
RS & Linearity
  • RS Total / RS 1M/2M/4M/6M — Relative Strength scores; see the dedicated RS Rating tab for how to read these.
  • Lin 1M / Lin 3M — "linearity" of the price trend (0–1); higher means a smoother, steadier climb rather than a choppy one.
Fundamentals
  • MCap Cr / PE / ROE / Debt — standard fundamental metrics, market cap shown in Crores.
  • EPS Q1%/Q2% and Sales Q1%/Q2% — latest and previous quarter YoY growth.
  • Holdings % — combined Promoter (P), Employee Trust (E), and Public (D) shareholding in one compact cell.
Activity & classification
  • Volume / Turnover — shown compactly (K/M/Cr) rather than raw numbers.
  • Vol↑ / Del↑ — checkmarks for above-average volume/delivery.
  • Tradable — ⚡ YES pill for stocks flagged as currently tradable; row also gets a subtle teal highlight.
  • Macro Sector / Sector / Industry / Basic Industry — full classification path.
  • All Index — hidden by default (tick "Show All Index" near the row-count selector to reveal); shows which NSE indices include the stock.

💪 Understanding RS Rating

Relative Strength measures how a stock's price performance compares to the rest of the market — the single most important column here.

RS Total (0–400) is a composite score blending performance across the 21/42/84/126-day (1/2/4/6-month) windows, weighted so recent strength counts more without ignoring longer-term trend. RS 1M/2M/4M/6M are the individual timeframe scores feeding into it.

Reading the color-coded badges
RS Total ≥ 370 top-tier momentum leader
RS Total 300–369 solid relative strength
RS Total < 300 lagging the market
How to use it: sort by RS Total descending to surface the market's strongest momentum names first, then layer on fundamental filters (PE, ROE, EPS growth) to narrow toward quality leaders rather than just any high-RS stock.

🔍 Peer Comparison Popup

Click any stock's Code cell in the table to open it.

The popup shows two ranked tables, both sorted by RS Total (highest first), with the clicked stock highlighted in teal so you can instantly see where it ranks:

  • Basic Industry Peers — every stock sharing the exact same Basic Industry classification.
  • Industry Peers — the broader set of stocks sharing the same Industry (a superset of the basic industry group).

Each row shows RS Total, EPS Q1%/Q2%, Sales Q1%/Q2%, Market Cap, Price Band, and 1M/3M Linearity — enough to judge whether a stock is a leader or laggard within its own peer group, not just the broader market.

Why this matters: a stock with a modest RS Total can still be the strongest performer in a weak industry — and a high RS Total stock might just be riding a strong sector tailwind. Peer comparison reveals which is which.

📈 Instant TradingView Charts

Click any stock's Name cell to open it.

Clicking a company name opens that stock's live chart directly on TradingView in a new tab — using the format NSE:SYMBOL — so you can jump from screener to chart analysis in one click without searching manually.

Symbols containing & (e.g. M&M) are automatically converted to _ to match TradingView's naming convention.

📊 Industry Performance Heatmap

Click 📊 Industry in the header.

This is a market-wide view (not affected by your current filters) showing every Industry's average 1D/1M/2M/4M/6M % change across all its stocks, with heat-coloring — deeper green for stronger average gains, deeper red for steeper average declines.

Sorting & drilling down
  • Click any column header to sort by that timeframe.
  • Click any row to drill into that industry's Basic Industries, with the same heatmap and sorting, plus a breadcrumb showing the full path back to Macro Sector.
Use case: spot which industries are leading or lagging the market right now, then drill in to find exactly which sub-segment is driving that move before searching for individual stocks.

📌 Saved Searches

Save filter combinations locally in your browser and re-run them anytime — even combine several at once.
Saving a search

Set up any combination of filters, click the 💾 button next to Clear, give it a name, and save. It's stored in your browser's local storage — it stays until you delete it or clear browser data, and is never sent anywhere.

Running searches
  • Click 📌 Saved in the header to open the panel.
  • Click the ▶ button on a single card to load that search — all matching filters get filled in and applied.
  • Tick the checkbox on two or more cards, then click Run Selected — each search runs independently, and the results are combined into one de-duplicated list (a stock matching multiple searches only appears once). A blue banner confirms which searches are active; click ✕ on it to return to normal filtering.
Managing saved searches

Use ☐ All to select/deselect everything at once, and 🗑 Delete to remove selected searches (with confirmation).

⚡ TradingView Watchlist Export

Turn any filtered result into watchlists ready to import into TradingView.

Once a filter is active (results are fewer than the full stock list), an amber ⚡ TV Watchlist button appears in the stats bar. Click it to open the export modal.

Choosing chunk size

TradingView limits watchlist size by plan (30 on Free, 100 on Essential, 500 on Plus, 1000 on Premium+). Pick the matching option, or enter a custom number — your filtered stocks are automatically split into that many stocks per list.

Importing

Each chunk shows a ready-to-copy text block in NSE:SYMBOL format. Click 📋 Copy, then in TradingView open the Watchlist panel → ⋮ → Import Watchlist and paste.

Symbols with & are auto-converted to _ to match TradingView's symbol format.

📲 Installing as an App

This screener works as a installable Progressive Web App for faster, app-like access.

On supported browsers (Chrome, Edge, Samsung Internet on Android; Chrome/Edge on desktop), a prompt appears a few seconds after your first visit offering to install the screener to your home screen or desktop. You can dismiss it — it'll politely wait 15 days before asking again.

Why install it
  • Opens in its own window without browser address bars/tabs.
  • Static assets (HTML, CSS, fonts) load instantly from local cache after the first visit.
  • Same-day repeat visits often skip the data download entirely if nothing's changed yet.
iPhone/iPad (Safari)

Safari doesn't support the install prompt automatically — tap the Share icon, then Add to Home Screen manually.

💡 Pro Tips

Small habits that get the most out of this screener.
  • Sort by RS Total first to find momentum leaders, then check their NR (Narrow Range) column for possible breakout setups.
  • Before buying into a "strong" stock, open its Peer Comparison popup — confirm it's actually a leader within its own industry, not just riding a sector-wide move.
  • Use Is Tradable ⚡ as a first-pass filter if you only care about stocks you can currently act on.
  • Build a few go-to Saved Searches (e.g. "High RS + Low PE", "Narrow Range Setups") so daily screening takes seconds, not minutes.
  • Check the Industry Performance heatmap before diving into individual filters — it tells you which sectors are worth focusing on today.
  • Press Esc to quickly close any open popup.
  • Click any sortable column header twice to flip between strongest-first and weakest-first ordering.

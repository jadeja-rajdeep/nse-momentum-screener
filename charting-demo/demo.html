fast-chart.js

Modular canvas chart library — main pane + synced RSI pane, code-driven lines/boxes/markers, theme switch, and a fast non-interactive thumbnail mode.

Scroll to zoom · drag to pan · move mouse for synced crosshair across both panes. All lines/boxes/markers on this chart were added via code (chart.addLine / chart.addMarkers / chart.addOverlay) — there's no mouse-driven drawing tool, by design.

Compact / thumbnail mode

No axes, no crosshair, no pointer listeners at all (interactive:false) — used in cards/lists where you show many small charts and want the fastest possible render.

🏠 What Is This Screener?

A free, no-login, single-file NSE stock screener built for momentum-based research — runs entirely in your browser.

This tool loads a daily snapshot of all NSE-listed stocks from a file called m.json and gives you a fast, flexible workspace to filter, rank, compare, and track them. There is no server, no account, no subscription. Everything runs locally in your browser.

The data refreshes once per day after market close (typically around 5 PM IST). The screener automatically serves cached data before 5 PM and fetches fresh data after 5 PM — so you never need to manually reload.

🧭 What you can do here
  • Screen stocks by RS Rating, sector, market cap, fundamentals, price band, F&O eligibility, narrow range days, volume/delivery activity, and more — using a powerful multi-select filter panel.
  • Rank by momentum using the composite RS Total score (0–400), which blends 1/2/4/6-month relative strength into a single sortable number.
  • Compare peers — click any stock code to instantly see its Basic Industry and Industry peers, ranked by RS, so you can tell if a stock is a leader or a laggard within its own group.
  • Read the sector map — the Industry Performance heatmap shows which industries are leading or lagging, drillable all the way to Basic Industry level, with checkboxes to apply any group directly to your filters.
  • Save and combine filters — named Saved Searches let you build a library of screening criteria and run them individually or merge multiple searches into a single de-duplicated result.
  • Manage personal watchlists — star any stock to add it to a named watchlist, build multiple lists, and filter the main table to show only your watchlist stocks.
  • Export to TradingView — turn any filtered result into a ready-to-import TradingView watchlist, auto-split by your plan's limit.
  • Jump to charts — click any stock name to open its live chart on TradingView instantly.
⚠ Important — Your Data Lives in This Browser

All personal data — Saved Searches, Watchlists — is stored in your browser's localStorage. This data is local to this device and this browser only. It is not backed up anywhere automatically.

Before clearing your browser history, cache, or site data — export a backup first. Use ⚙ Settings → Export Settings to download a JSON backup file. You can import it back at any time to restore everything. See the Settings & Tools tab for details.

New here? Open the ⚙ Filters panel, set an RS Total Min of 300, tick ⚡ Is Tradable, and sort by RS Total descending. You now have a filtered list of momentum leaders you can currently act on. Then click any Code to see Peer Comparison and confirm it is leading within its group.

⚙ Filters Panel

Click ⚙ Filters in the header to show or hide. Every filter is applied instantly — no submit button needed.
🔎 Text Search

The Search Code / Name box matches against both the stock ticker and the full company name. Partial matches work — typing tata shows all TATA group companies. Case-insensitive and instant.

🗂 Multi-Select Classification Dropdowns

Macro Economic Sector, Sector, Industry, Basic Industry, and Price Band all support multiple selections. Click the dropdown, tick as many values as you want, and use the search box inside each to find options quickly.

  • Within one dropdown: OR logic. Sector = Auto + IT shows stocks from either.
  • Across dropdowns: AND logic. Sector = Auto AND RS Min = 300 shows only Auto stocks with RS ≥ 300.
  • Use Select All / Clear buttons inside each dropdown for quick bulk actions.
  • These dropdowns are cascade-linked — see the Sector Cascade tab.
📏 Range Filters — complete list
  • RS Total (0–400) — composite momentum score. Min = 300 for strong RS, Min = 370 for top-tier leaders.
  • RS 1M / 2M / 4M / 6M — individual timeframe RS, each 0–100. Consistent high scores across all four = sustained momentum, not just a recent spike.
  • 1M / 2M / 4M / 6M Chng% Min-Max — absolute price-change filters for each period. Use a tight min/max band to find stocks that have gone flat over that timeframe. Example: 6M Chng% -5 to 5 keeps stocks trading near their 6-month base, often useful for spotting flat-base or base-breakout candidates.
  • Market Cap (₹ Cr) — enter in Crores (500 = ₹500 Cr). Use to separate large/mid/smallcap research.
  • Close Price (₹) — filter by absolute price level.
  • PE / ROE — standard valuation and quality ratios.
  • Net Turnover (₹ Cr) — daily traded rupee value. Ensures minimum liquidity.
  • Promoter Hold % — min/max promoter shareholding. High holding often signals confidence.
  • Narrow Range (≥ days) — stocks in tight consolidation for N+ consecutive days. NR ≥ 4 often precedes a breakout.
  • 1M / 3M Linearity (≥) — 0 to 1. Values above 0.65–0.7 mean the stock has been rising in a smooth, clean trend — not a jagged spike.
  • EPS Latest / Prev Qtr % — YoY earnings growth for the two most recent quarters. Both positive = sustained earnings momentum.
  • Sales Latest / Prev Qtr % — same for revenue. Strong sales + strong EPS = highest-quality combination.
✅ Checkbox Filters
  • Vol ↑ — today's volume is above historical average. Unusual activity signal.
  • Turnover ↑ — same for rupee value traded.
  • Delivery ↑ — delivery volume above average. Spikes in delivery indicate genuine accumulation, not intraday noise.
  • ⚡ Is Tradable — the most important quick-filter. Tradable stocks get a glowing teal row highlight. Use this as your first filter on most days.
  • 📑 F&O — restricts to stocks in the Futures & Options segment. Useful for traders needing hedging capability or F&O-grade liquidity.
🏆 Peer & Industry Rank Filters

Six percentile-based filters let you narrow by where a stock's peer group or industry ranks. Enter a number 1–100; enter 10 to keep only the top 10%, 25 for the top quarter, etc. All six can be combined with each other and with any other filter.

  • BI Rank Top % — keep only stocks whose Basic Industry peer rank (by RS Total) places them in the top N% of their Basic Industry group. E.g. 20 keeps only stocks ranked in the top 20% of peers by RS momentum. Mirrors the ranking in the Peer Comparison popup (Basic Industry table).
  • Ind Rank Top % — same but for the broader Industry peer group. E.g. 10 keeps only the top 10% RS performers within their Industry. Mirrors the Peer Comparison popup (Industry table).
  • BI 5D Rank Top % — keep only stocks whose Basic Industry group ranks in the top N% of sibling Basic Industries (under the same parent Industry) by average 5-day change%. Same ranking as the drill-down popup in 📊 Industry sorted by 5D%. E.g. 25 keeps stocks in Basic Industries that are top-quartile performers this week within their parent Industry.
  • Ind 5D Rank Top % — keep only stocks whose Industry ranks in the top N% of all 64 NSE Industries by average 5-day change%. Same ranking as the 📊 Industry popup sorted by 5D%. E.g. 10 keeps stocks in the top 6–7 best-performing industries of the past week.
  • BI 1M Rank Top % — same as BI 5D Rank but using average 1-month change%. Identifies stocks in Basic Industry sub-groups that have been leading over a longer window, not just this week.
  • Ind 1M Rank Top % — same as Ind 5D Rank but using average 1-month change%. Keeps stocks in industries that have been trending for a full month, same as the 📊 Industry popup sorted by 1M%.
Combining rank filters: set Ind 5D Rank ≤ 20% + Ind 1M Rank ≤ 25% + Is Tradable to find tradable stocks in industries that are both short-term and medium-term leaders. Add BI 5D Rank ≤ 33% to ensure their specific sub-group is also performing well within that industry.
⭐ Watchlist Filter (Multi-Select Dropdown)

Once you have personal watchlists created (see Watchlists tab), a Watchlist dropdown appears in the filter panel. Select one or more watchlists to show only those stocks. Multiple selections use OR logic — a stock in any selected list is shown.

🧹 Clearing & Saving
  • Click ✕ Clear to reset every filter at once — dropdowns, checkboxes, and all range inputs.
  • Click 💾 (next to Clear) to save all current active filters as a named Saved Search. A preview of all active filters is shown before you confirm the name.

🔗 Sector Cascade Logic

The four classification dropdowns are linked — selecting a parent narrows the children automatically, so you never get an impossible combination.

NSE classifies every stock into a 4-level hierarchy:

Macro Economic Sector → Sector → Industry → Basic Industry

Example: Consumer Discretionary → Consumer Services → Leisure Services → Restaurants

How the cascade behaves
  • Selecting one or more Macro Sectors instantly limits Sector to only what exists under those macro sectors — and cascades the same constraint to Industry and Basic Industry.
  • Selecting Sectors narrows Industry and Basic Industry to what belongs under those sectors.
  • Selecting Industries narrows Basic Industry to just that industry's sub-categories.
  • Selecting multiple values at any level shows the union — two Sectors selected means all Industries under either sector are shown.
  • Clearing a parent automatically widens its children back to the full available list.
  • If a previously-selected Basic Industry becomes invalid after changing its parent Sector, it is automatically dropped — no impossible combinations.
Shortcut via Industry Performance popup

In the 📊 Industry popup, each row has a checkbox. Checking it automatically fills the full chain (Macro → Sector → Industry, or additionally Basic Industry in the drill-down) into the filter dropdowns and re-applies the filter — no manual cascade navigation needed.

Why this matters: you will never accidentally create a filter that returns zero results because you picked a Basic Industry that doesn't exist under your selected Sector. Every dropdown only shows options that actually have stocks given the current parent selection.

📋 Reading the Table

Every column header is clickable to sort — click once for descending (highest first), click again to reverse. Two columns are frozen while scrolling: Code and Name on desktop; Code only on mobile.
🔑 Interactive columns
  • Code — click to open the Peer Comparison popup. A ☆ star icon appears next to the code; click it to add/remove the stock from a personal watchlist.
  • Name — click to open that stock's live chart on TradingView in a new tab.
📉 Price & Change columns
  • Close ₹ — latest NSE end-of-day closing price.
  • NR — Narrow Range day count. Shown in amber when ≥ 1 (4 means the stock has been in a tight range for 4 days — a common pre-breakout coiling setup). Displays — when 0.
  • 5DR% — 5-Day Range percentage: the % spread between the highest high and lowest low over the last 5 trading days. Shown colour-coded: green ≤ 6.5% = ideal tight consolidation, prime pre-breakout territory; amber ≤ 7.5% = acceptable in rising stocks; above 7.5% shows as muted — too wide for a clean setup. Works alongside NR: NR counts the consecutive days, 5DR% measures how tight the actual range is. Use both together for the highest-quality coiling patterns.
  • Tradable — ⚡ YES pill for stocks flagged as currently tradable. Rows also get a subtle teal left-border highlight so they stand out while scrolling.
  • F&O — ✓ checkmark for stocks in the Futures & Options segment.
  • 1D / 5D / 1M / 2M / 4M / 6M Chg% — price changes over each timeframe. Green = positive, red = negative. Consistent multi-timeframe gains = genuine trend, not a single-day spike. The 1M/2M/4M/6M Chg% filters can also be used in reverse: a narrow band around zero, such as -5 to 5, highlights stocks that have been moving sideways over that period and may be building a flat base.
💪 RS & Linearity columns
  • RS Total — composite Relative Strength score, 0–400. Green badge ≥ 370 = top-tier; amber 300–369 = solid; red < 300 = lagging. See the RS Rating tab for full explanation.
  • RS 1M / 2M / 4M / 6M — individual timeframe RS scores, each ranked 0–100 across all NSE stocks. Green ≥ 95 = top 5%; amber ≥ 80 = above average.
  • Lin 1M / Lin 3M — trend linearity, 0 to 1. Near 1.0 = smooth, straight uptrend; near 0 = choppy/random. Values above 0.7 indicate clean trending moves — better setups than high RS with erratic price action.
📊 Fundamental columns
  • MCap Cr — market capitalisation in Crores (K Cr = thousands of Crores).
  • PE / ROE % / Debt — standard fundamental metrics.
  • EPS Q1% / Q2% — YoY EPS growth for the latest and previous reported quarters. Both positive = sustained earnings growth.
  • Sales Q1% / Q2% — same for revenue. Strong sales + strong EPS = highest-quality fundamental combination.
  • Holdings % — three values in one cell: P = Promoter %, E = Employee Trust %, D = Public (Diffuse) %.
📦 Volume & Activity columns
  • Volume — traded shares shown compactly (K = thousands, M = millions).
  • Turnover — traded rupee value in ₹ Cr.
  • Del% — delivery percentage. High delivery % on a big volume day = genuine accumulation, not intraday activity.
  • Vol↑ / Del↑ — ✓ when volume or delivery is above the stock's historical average.
🏆 Peer & Industry Ranking columns

Six ranking columns give you two different lenses on where a stock stands relative to its peers. All are colour-coded: green = top 10%, teal = top 25%, grey = top 50%, dark = below 50%. Displayed as rank/total (e.g. 3/28 = ranked 3rd out of 28).

  • BI Rank — the stock's position within its Basic Industry group, ranked by RS Total (highest RS = rank 1). Tells you if this stock is the momentum leader within its most specific peer group. Same data as the Basic Industry table in the Peer Comparison popup.
  • Ind Rank — the stock's position within its broader Industry group, ranked by RS Total. Same data as the Industry table in the Peer Comparison popup.
  • BI 5D — where this stock's Basic Industry ranks among all sibling Basic Industries under the same parent Industry, ranked by the average 5-day change% of all stocks in each Basic Industry group. Exactly matches the drill-down popup you get by clicking an Industry row in 📊 Industry and sorting by 5D%. Rank 1 = the best-performing Basic Industry sub-group for the week.
  • Ind 5D — where this stock's Industry ranks among all 64 NSE Industries by average 5-day change%. Exactly matches what you see when you sort the 📊 Industry popup by 5D% — rank 1 = the best-performing industry of the week across the whole market.
  • BI 1M — same as BI 5D but ranked by average 1-month change% within the sibling Basic Industry group. Identifies which sub-segment has been sustaining momentum over a longer window.
  • Ind 1M — where this stock's Industry ranks among all 64 Industries by average 1-month change%. Matches the 📊 Industry popup sorted by 1M%.
How to use them together: BI Rank/Ind Rank tell you if a stock leads its peers on RS momentum. BI 5D/Ind 5D and BI 1M/Ind 1M tell you if its entire group is in a leading industry right now. A stock with BI Rank = 1/20 AND Ind 1M = 2/64 is the strongest stock in the strongest industry — the ideal combination for momentum trading.
🏷 Classification & Index columns
  • Macro Sector / Sector / Industry / Basic Industry — full 4-level NSE classification path.
  • Band% — NSE price circuit limit (0 = no limit, 2/5/10/20%).
  • All Index — hidden by default. Tick Show All Index in the stats bar to reveal which NSE indices (NIFTY 50, NIFTY 500, etc.) the stock belongs to.

💪 Understanding RS Rating

Relative Strength measures how a stock's price performance compares to every other NSE stock — the single most important ranking in this screener.

RS Total (0–400) is a composite score blending the 1-month, 2-month, 4-month, and 6-month price performance of each stock relative to all other stocks, weighted so that recent momentum counts more than older performance. It is not absolute return — it is a relative ranking. A stock can have strong RS even in a falling market if it is falling less than others.

Individual timeframe scores (RS 1M / 2M / 4M / 6M)

Each timeframe score is ranked 0–100 across the entire universe:

  • Score of 99 = outperformed 99% of all NSE stocks over that period.
  • Score of 50 = median — exactly average performance.
  • Score of 10 = weaker than 90% of all stocks.
How to read the colour-coded badges
RS Total ≥ 370 — top-tier momentum leader. The market is consistently bidding these up across multiple timeframes.
RS Total 300–369 — solid relative strength, above-average performers worth investigating.
RS Total < 300 — lagging the market; approach with caution unless you have a specific thesis.
What patterns to look for
  • Consistent RS across all 4 timeframes (all ≥ 80) = genuinely sustained momentum, not a one-month wonder.
  • Rising RS 1M with lower RS 6M = a stock that was weak for months but just starting to show life — potential early-stage breakout candidate.
  • High RS 6M but declining RS 1M = the big move may be over and momentum is fading — be cautious about chasing it.
  • High RS + high Linearity = stock has been climbing steadily, not erratically — the cleanest kind of uptrend for breakout-style trading.
Starting point: sort by RS Total descending, set RS Min = 300, tick Is Tradable. You now have momentum leaders you can act on. Open Peer Comparison on any interesting name to confirm it leads its own industry — not just riding a broad sector wave.

🔍 Peer Comparison Popup

Click any stock's Code cell to open it. Instantly see where a stock ranks within its own industry group.

A full-screen overlay shows two ranked tables, both sorted by RS Total highest first, with the clicked stock highlighted in teal:

  • Basic Industry Peers — every stock in the exact same Basic Industry (the narrowest, most comparable group).
  • Industry Peers — the broader Industry group (a superset of multiple Basic Industries).

Each row shows: Code, Name, RS Total badge, EPS Q1%/Q2%, Sales Q1%/Q2%, Market Cap, Price Band, and 1M/3M Linearity.

How to use it effectively
  • If the clicked stock sits near the top of the Basic Industry table, it is genuinely leading its peer group — a much stronger signal than high RS Total alone.
  • If it sits in the middle or bottom, its RS may be inflated by a sector-wide move, and a better name may exist in the same group.
  • Use it to find the strongest name in a hot sector: filter by a sector, click each top-RS name, confirm it's #1 or #2 in its Basic Industry before adding to your list.
  • Sort the peer table columns (click any header) to re-rank by EPS growth, Sales growth, or Linearity depending on your strategy.
Why this matters: sector news lifts entire industries, masking which stocks are actually driving the move. Peer Comparison reveals the real leaders from the passively-lifted names.

📈 Instant TradingView Charts

Click any stock's Name cell in the main table to jump directly to its live chart on TradingView.

Clicking a company name opens that stock's chart on TradingView in a new browser tab using the format NSE:SYMBOL — move from screener research to chart analysis in one click, without searching TradingView manually.

Symbol formatting

All codes are prefixed with NSE: automatically. Any & characters in NSE codes (e.g. M&M) are converted to _ to match TradingView's naming convention. This is handled automatically.

Bulk export to TradingView

For bulk export, use the ⚡ TV Watchlist button in the stats bar (visible when a filter is active). See the TV Watchlist tab for full details.

📊 Industry Performance Heatmap

Click 📊 Industry in the header. A full market-wide view of sector health — not affected by your current filters.

Shows all 64 NSE Industries with the average 1D / 5D / 1M / 2M / 4M / 6M % change across every stock in each industry, using heat-colouring: deeper green = stronger average gains, deeper red = steeper average losses.

Covers the entire NSE universe regardless of your current filters — this is intentional, giving you an objective market-wide view.

Sorting & Drilling Down
  • Click any column header to sort — sort by 1M to see what has been trending for a month; sort by 1D to see today's rotation.
  • Click any row to drill into that industry's Basic Industries, revealing which sub-segments are driving or dragging the industry average.
  • The breadcrumb at the top of the drill-down shows the full path: Macro Sector → Sector → Industry.
  • Both tables support independent sorting by any column.
☑ Apply to Filters checkbox

Every row in both tables has a checkbox. Checking it adds that row's full classification chain into the main filter dropdowns and re-applies the filter immediately — without closing the popup.

  • Check multiple rows to build an OR combination across industries (e.g. Pharmaceuticals + Speciality Chemicals).
  • Unchecking a row removes only that industry's values from the filter, leaving others intact.
  • Checkboxes reflect the current filter state — if Pharmaceuticals is already selected in the filter, its row appears checked when you open the popup.
Workflow: open the Industry heatmap at the start of your session. Sort by 1M to find trending sectors. Drill into the top 1–2 sectors to find leading Basic Industries. Check those rows to apply them to your filters. Close the popup — you now have a focused list of the right stocks to research, without typing anything into filter boxes.

📌 Saved Searches

Save any filter combination under a custom name and re-run it anytime — or combine multiple saved searches into one merged result.
Saving a search
  1. Set up any combination of filters in the filter panel.
  2. Click the 💾 button next to the Clear button.
  3. A preview of every active filter and its values is shown. Type a descriptive name (e.g. "High RS F&O NR Setup") and click Save Search.
  4. The search is stored in your browser's localStorage immediately and appears in the 📌 Saved panel.

Saved searches persist until you delete them or clear browser data. Nothing is ever sent anywhere. Use ⚙ Settings → Export Settings to back them up.

Running a single saved search

Click 📌 Saved in the header to show the panel. Click the ▶ play button on any card — all its filter values are loaded into the filter panel and applied immediately. The filter panel opens so you can see and adjust what was set.

Combining multiple saved searches

Tick the checkboxes on two or more cards, then click ▶ Run Selected. Each search runs independently, and results are merged into one de-duplicated list (a stock matching multiple searches appears only once).

A blue active banner confirms which searches are combined and how many unique stocks resulted. Click ✕ Clear on the banner to return to normal mode.

Example: "High RS IT" + "High RS Pharma" run together gives the best momentum names from both sectors in one list — without manually ORing the sector filter.

Managing saved searches
  • Use ☐ All to select/deselect all cards at once.
  • Select cards and click 🗑 Delete to remove them (confirmation prompt appears).
  • The count is shown next to the 📌 button in the header.
⚠ Backup reminder

Saved searches are stored in browser localStorage only. They will be lost if you clear browser data. Use ⚙ Settings → Export Settings to download a backup before clearing browser data or switching devices.

⭐ Personal Watchlists

Star any stock to add it to a named watchlist. Create multiple lists. Filter the main table to show only your watchlist stocks.
Adding a stock — the star icon

Each row in the main table shows a star icon next to the stock code. Dimmed outline (☆) = not in any watchlist. Filled gold (★) = in at least one watchlist.

  • No watchlists yet: clicking the star prompts you to create your first watchlist and name it. The stock is added immediately.
  • One watchlist: clicking the star instantly toggles the stock in/out — one click, no extra prompt.
  • Multiple watchlists: a small checkbox popover lists all your watchlists. Tick the ones you want this stock in. A stock can belong to multiple watchlists at the same time.
Bulk-adding filtered stocks

When a filter is active, a ➕ Add to Watchlist button appears in the stats bar. Clicking it adds every stock currently shown in filtered results to a watchlist of your choice. If you have 2+ watchlists, a prompt asks which list (or lets you create a new one).

Filtering by watchlist

The Watchlist multi-select dropdown in the filter panel lists all your watchlists. Select one or more to show only those stocks in the main table. Combines with all other filters using AND logic — filter your watchlist to only show tradable or high-RS names from it.

Managing watchlists — ⭐ Watchlists panel

Click ⭐ Watchlists in the header to open the management panel:

  • View — click ▶ View on any card to filter the main table to that watchlist instantly.
  • Rename — double-click the watchlist name to rename it inline. Press Enter or click away to confirm.
  • Delete — select one or more cards and click 🗑 Delete Selected to remove them and all their stored stocks (with confirmation).
  • Each card shows the watchlist name and stock count.
⚠ Backup reminder

Watchlist data is stored in browser localStorage only. It will be lost if you clear browser data or switch to a different browser/device. Use ⚙ Settings → Export Settings to back up all your watchlists before any browser maintenance. You can restore them at any time using Import Settings.

⚡ TradingView Watchlist Export

Turn any filtered screener result into watchlists ready to import directly into TradingView — with automatic chunk splitting for plan limits.

When a filter is active (results fewer than the full universe), an amber ⚡ TV Watchlist button appears in the stats bar. Click it to open the export modal.

Choosing chunk size

TradingView limits watchlist size by plan: 30 stocks on Free, 100 on Essential, 500 on Plus, 1000 on Premium+. Select your plan — filtered stocks are automatically split into chunks of that size. You can also enter a custom number.

Copying and importing
  1. Each chunk shows a text block of NSE:SYMBOL,NSE:SYMBOL,….
  2. Click 📋 Copy on a chunk to copy it. The button turns green with ✓.
  3. In TradingView, open the Watchlist panel → ⋮ → Import Watchlist → paste.
  4. Repeat for each additional chunk.
Symbol formatting

All symbols are prefixed with NSE: and any & characters (e.g. M&M → NSE:M_M) are converted to _ automatically.

This export works with multi-search combined results too — run two or three Saved Searches together to get a merged unique list, then export the whole thing to TradingView in one step.

⚙ Settings & Tools

Click the ⚙ icon button in the header (between ❓ Help and 👤 Author) to open Settings.
📤 Export Settings — Backup Your Data

Downloads all your personal data as a single JSON file named nse-screener-backup-YYYY-MM-DD-HHmm.json. The backup includes:

  • All Saved Searches — names and full filter state for each.
  • All Watchlists — list names and the stock codes in each list.

When to use it: before clearing browser history or cache, before switching to a new computer or browser, or periodically as a routine backup. Since all data lives only in localStorage, this is the only way to protect it.

📥 Import Settings — Restore From Backup

Click the Import Settings area to open a file picker. Select a previously exported .json backup file. The screener will:

  1. Validate the file structure to confirm it is a genuine screener backup.
  2. Restore your Saved Searches and Watchlists to localStorage, replacing anything currently stored.
  3. Reload the page automatically after 2 seconds so all restored data initialises correctly.

Important: importing overwrites existing data — it does not merge. If you want to keep both old and new data, export first before importing.

⚠ Always backup before clearing browser data

Your Saved Searches and Watchlists are stored exclusively in this browser's localStorage. Clearing browser history, cache, cookies, or site data will permanently delete them. There is no cloud backup, no server, no account to recover from. Use Export Settings regularly.

📲 Installing as an App

This screener is a Progressive Web App (PWA) — install it to your home screen or desktop for faster, app-like access.

On supported browsers (Chrome, Edge, Samsung Internet on Android; Chrome/Edge on desktop), a 📲 Install NSE Screener prompt appears a few seconds after your first visit. Dismiss it and it will ask again after 15 days.

Why install it
  • Opens in its own standalone window — no browser address bars, toolbars, or tabs.
  • Static assets (HTML, CSS, fonts) load from local cache instantly after the first visit.
  • Smart caching: same-day repeat visits skip the data download entirely before 5 PM IST on weekdays, or all day on weekends/holidays — saving ~4 MB per repeat visit.
  • Works offline for browsing previously loaded data.
Updates

💡 Common Use Cases

Real-world workflows — how to get the most out of this screener for different research goals.
📅 Daily Morning Screening (5–10 minutes)
  1. Open the 📊 Industry heatmap. Sort by 1D to see what moved overnight. Check 1M to confirm which sectors have been in trend.
  2. Click into the 1–2 leading sectors to drill into Basic Industries and identify the strongest sub-segments.
  3. Check those rows to apply them directly to your main filters.
  4. Tick ⚡ Is Tradable and set RS Total Min = 300. Sort by RS Total descending.
  5. Scan the top 10–20 names. Click each Code to check Peer Comparison — confirm it is leading its own group before shortlisting it.
  6. Star (★) your shortlist into a named watchlist like "Today's Setups" for easy reference through the day.
🔍 Finding Narrow Range Breakout Setups
  1. Set Narrow Range ≥ 3 or 4 — stocks coiling for multiple days.
  2. Set RS Total Min = 270–300 — consolidating within an existing uptrend.
  3. Optionally set Vol ↑ — narrow range stocks also showing volume pickup today signal an imminent move.
  4. Sort by Narrow Range descending to surface the most extended coils first.
  5. Click each stock's Name to open TradingView and visually confirm the base before acting.
  6. Save this filter as a Saved Search named "NR Breakout Setups" for daily reuse.
Finding Flat Base / Long Consolidation
  1. Use the 1M / 2M / 4M / 6M Chng% min-max filters to define how flat the stock has been over your chosen period.
  2. For a longer base, set 6M Chng% Min = -5 and 6M Chng% Max = 5. This keeps stocks whose current price is close to where it was 6 months ago.
  3. Add 5D Range% Max or Narrow Range >= 3 to focus on names that are also tightening near the right side of the base.
  4. Combine with RS Total Min, Vol ↑, or Delivery ↑ to find bases that are starting to attract momentum or accumulation before a breakout.
📈 Building a Momentum Portfolio Watchlist
  1. Set RS Total Min = 320, RS 1M Min = 80, RS 6M Min = 75 (sustained momentum across timeframes).
  2. Set Lin 3M ≥ 0.65 (smooth, linear trend — not a spike).
  3. Set Delivery ↑ checked (institutional buying signal).
  4. Optionally set ROE Min = 15 and Promoter Hold Min = 40 for quality filtering.
  5. Review the list. Click each Code for Peer Comparison — confirm the stock leads its Basic Industry. Star the best into a watchlist named "Core Momentum".
  6. Save the filter combination as a Saved Search for weekly reuse as market conditions evolve.
💊 Researching a Specific Sector
  1. Open the Industry dropdown. Search and select your target (e.g. "Pharma"). The cascade narrows Sector/Industry/Basic Industry automatically.
  2. Further refine to a specific Basic Industry if needed (e.g. "Agrochemicals" under Speciality Chemicals).
  3. Sort by RS Total descending to rank all stocks in that sector by momentum.
  4. Click the top 3–5 Codes to compare peer standing and find the true sector leaders.
  5. Use the ⚡ TV Watchlist button in the stats bar to export the whole filtered group to TradingView for chart review.
🔄 Multi-Strategy Daily Universe
  1. Create separate Saved Searches for each strategy: "High RS F&O Largecap", "NR Setups Midcap", "High EPS Growth IT".
  2. Each morning, open 📌 Saved, select all your strategy searches, and click ▶ Run Selected.
  3. The merged de-duplicated result shows every stock qualifying for at least one strategy — your complete daily research universe.
  4. Export the combined list to TradingView as a single watchlist for chart review.
⭐ Using Personal Watchlists Day-to-Day
  1. After your morning screening, star your top candidates into a named daily list like "Tracking June 16".
  2. During the day, select that watchlist in the Watchlist filter dropdown to focus the main table on just those stocks.
  3. Layer on additional filters (e.g. Vol ↑) to see which of your tracked stocks are showing activity.
  4. At the end of the week, use ⭐ Watchlists → rename or delete old lists as you build new ones.
  5. Before clearing browser data: ⚙ Settings → Export Settings to save all watchlists to a backup file.
📱 Getting the Most on Mobile
  • Install the PWA (see Install App tab) for the cleanest mobile experience — full screen, no browser chrome.
  • On mobile, only the Code column is frozen while scrolling horizontally. Tap Code for Peer Comparison; tap Name (visible when not scrolled right) for TradingView.
  • Use the ⚙ Filters toggle to hide the filter panel after setting your criteria — the table gets much more vertical space.
  • The Industry heatmap and Basic Industry drill-down work fully on mobile with horizontal scroll.
  • The star icon on each Code cell is 16px — easily tappable on touch screens.
💾 Keeping Your Data Safe — Checklist
  • All Saved Searches and Watchlists live in browser localStorage — lost if you clear browser data.
  • Use ⚙ Settings → Export Settings to download a backup JSON file before clearing cache or switching devices.
  • When moving to a new device or browser: export on old device, import on new one via ⚙ Settings → Import Settings.
  • The backup file includes all Saved Searches and all Watchlists in one portable JSON file.
  • Import replaces existing data — export first if you want to merge rather than overwrite.
